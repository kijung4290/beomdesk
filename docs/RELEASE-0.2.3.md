Electron에서 무설치형의 업데이트 교체 프로세스를 실행하는 방식을 수정했습니다.

- Windows GUI 프로세스에서 PowerShell을 직접 분리 실행할 때 초기화되지 않는 문제를 수정했습니다. 숨김 시작 프로세스가 독립 교체 프로세스를 준비하고, 준비 확인 뒤 앱을 종료합니다.
- 실제 Electron 프로세스가 종료된 뒤 파일 교체·해시 확인·백업이 끝나는 자동 검사를 추가했습니다.
- 설치형은 사용자 재시작 요청 뒤 추가 마법사 없이 업데이트합니다.

문서 입력과 미리보기, 검색·분류·즐겨찾기, 빠른 편집, 계산, 서식 27개와 원본 도구 연결 1,926개를 제공합니다. 이 중 직접 적용 가능한 연결은 1,747개이며, 일부 복잡한 기능은 원본 입력 창과 호환 구성 요소를 사용합니다. 모든 개별 도구를 실행 검증한 것은 아닙니다.

`setup.exe`는 설치형, `portable.exe`는 무설치형입니다. 한글 자동화에는 설치된 한컴오피스 한글이 필요합니다. Windows 코드 서명 인증서는 적용하지 않았습니다.

초기 0.2.0~0.2.2 무설치형은 이 버전의 EXE를 직접 내려받아 교체해 주세요. `BeomDeskData` 폴더는 그대로 보관하세요.
