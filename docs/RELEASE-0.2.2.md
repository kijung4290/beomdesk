최신 수정본은 [0.2.3](https://github.com/kijung4290/beomdesk/releases/tag/v0.2.3)을 사용해 주세요. 초기 배포본의 무설치 업데이트 적용 문제를 수정했습니다.

업데이트 적용 과정을 보완했습니다.

- 설치형은 **업데이트 후 다시 시작**을 누르면 추가 설치 마법사 없이 업데이트합니다.
- 무설치형은 교체 프로세스가 준비됐는지 확인한 다음 앱을 종료합니다. 교체 프로세스는 삭제될 수 있는 임시 실행 폴더 대신 설정 폴더에서 실행합니다.
- 교체 재시도 중에도 최초의 실행 파일 백업을 유지합니다.
- 실제 Windows 교체 프로세스의 종료 대기·해시 확인·파일 교체·백업을 자동 검사합니다.

문서 입력·미리보기, 도구 검색·즐겨찾기, 1,926개 도구 연결(직접 적용 1,747개), 한글 서식 27개를 제공합니다. 일부 복잡한 도구는 원본 입력 창과 호환 구성 요소를 사용합니다.

`setup.exe`는 설치형, `portable.exe`는 무설치형입니다. 한글 자동화에는 설치된 한컴오피스 한글이 필요합니다. Windows 코드 서명 인증서는 적용하지 않았습니다.

초기 0.2.0·0.2.1 배포본은 이번 설치 파일 또는 무설치 파일을 직접 내려받아 교체해 주세요. 초안·설정 폴더는 보관하세요.
