# 검증 기록

Windows x64와 실제 설치된 한컴오피스 한글에서 검사했습니다.

| 검사 | 확인한 내용 |
| --- | --- |
| Python 11개 검사 | 문서 순서, 표·Markdown·HTML 처리, 계산·날짜, 콜백 제한, 복사 상태 유지 |
| Node 7개 검사 | 업데이트 버전·파일·해시 검사, 불완전 다운로드 거절, 자동 다운로드 설정, 설치형 무인 적용, 실제 PowerShell 교체, Electron GUI 종료 후 교체 인계 |
| [설치된 0.2.3 앱](electron-smoke.json) | 도구 연결 1,926개·직접 적용 1,747개·서식 27개, 검색·즐겨찾기·계산·미리보기, 최소 창 크기, 종료 직전 초안 저장, 화면 오류 없음 |
| [한글 통합 검사](hwp-integration.json) | 별도 테스트 문서의 문장·표, 글꼴, 원본 자동화 입력, 직접 적용 도구, 표 도구 창, HWPX 저장과 XML 내용 |
| [설치형 업데이트](live-update-installed.json) | 공개된 0.2.2 → GitHub 0.2.3 다운로드·해시 확인·무인 설치·재시작, 기존 초안·즐겨찾기를 새 앱에서 다시 확인 |
| [무설치형 업데이트](live-update-portable.json) | 수정된 업데이트 엔진을 포함한 이전 버전 번호의 로컬 검증용 빌드 → GitHub 정식 0.2.3 파일로 교체·재시작, EXE 해시·이전 파일 백업·초안·설정 유지 |

무설치 업데이트의 검증용 이전 빌드는 공개된 초기 0.2.2와 다릅니다. 공개된 0.2.0~0.2.2 무설치형에서는 최신 EXE를 직접 내려받아 교체해야 합니다. `BeomDeskData` 폴더는 유지합니다.

원본의 1,926개 항목은 버튼 연결 수이며, 같은 기능이 여러 화면에 등장하는 경우도 포함합니다. 모든 개별 버튼이나 모든 한글·Office 버전 조합을 실행 검증한 것은 아닙니다. 복잡한 일부 기능은 추출된 원본 바이트코드와 입력 창을 사용합니다.
