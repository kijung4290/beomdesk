최신 수정본은 [0.2.3](https://github.com/kijung4290/beomdesk/releases/tag/v0.2.3)을 사용해 주세요. 초기 배포본의 무설치 업데이트 적용 문제를 수정했습니다.

Electron 기반 범피스 작업실의 첫 배포입니다.

- 설치형: `BeomDesk-0.2.0-setup.exe`
- 무설치형: `BeomDesk-0.2.0-portable.exe`
- 문서 작성·미리보기, 글자·문단·표 편집, 도구 검색·분류·즐겨찾기, 날짜·금액 계산
- 원본 연결 1,926개 / 직접 적용 1,747개 / HWP·HWPX 서식 27개
- GitHub Releases 기반 설치형·무설치형 업데이트, 다운로드 크기·SHA-512 검증

실제 한글에서 문장·표 생성, 글꼴 변경, 원본 도구 연결, HWPX 저장을 검증했습니다. Electron 앱의 검색·즐겨찾기·계산·미리보기, 작은 창에서의 버튼 표시, 종료 직전 초안 보관도 확인했습니다. 원본 도구 전부를 개별 실행 검증한 것은 아닙니다.

한글 문서 작업에는 설치된 한컴오피스 한글이 필요합니다. 일부 원본 기능은 Excel·PowerPoint도 필요합니다. 원본의 세부 기능은 추출 바이트코드를 사용하는 호환 구성 요소로 보존했습니다.

Windows 코드 서명 인증서는 적용하지 않았습니다. Windows에서 게시자 확인 또는 SmartScreen 안내가 나타날 수 있습니다.
