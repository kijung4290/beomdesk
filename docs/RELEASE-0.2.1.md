최신 수정본은 [0.2.3](https://github.com/kijung4290/beomdesk/releases/tag/v0.2.3)을 사용해 주세요. 초기 배포본의 무설치 업데이트 적용 문제를 수정했습니다.

자동 업데이트와 배포 흐름을 보완한 버전입니다.

- 새 버전을 백그라운드에서 자동으로 다운로드합니다. 문서 작업을 저장한 뒤 원하는 시점에 다시 시작해 적용할 수 있습니다.
- 설정에서 자동 확인·다운로드를 각각 끌 수 있습니다.
- 로컬 실행 진단에 버전·설치형/무설치형 구분을 기록합니다.
- 문서 생성, 1,926개 도구 연결(직접 적용 1,747개), 서식 27개와 기존 사용자 초안·즐겨찾기는 유지합니다.

`setup.exe`는 설치형, `portable.exe`는 무설치형입니다. 설치된 한컴오피스 한글이 필요하며, 일부 기능에는 Excel·PowerPoint가 필요합니다. 모든 원본 도구를 개별 실행 검증한 것은 아닙니다. Windows 코드 서명 인증서는 적용하지 않았습니다.
